# LeadFollow — Feature pillars

## Core engine
- Stage-aware follow-ups: post-showing, open-house thank-you, nurture
- Warm or professional tone with a no-pressure close
- Clear next step in every note

## Workflow & output
- Agents keep consistent follow-up without writing every note from scratch
- Copy ready to review and send
- Matched to where the lead actually is in the funnel

## Trust & control
- Decision-support for outreach copy — not a CRM replacement
- No fabricated reply-rate claims
- Demo mode without a live API key
